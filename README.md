# ⚡ SFTPulse

一个**通用的 SSH / SFTP 桌面客户端**（Windows）。把「连服务器、传文件、开终端、跑部署命令、同步数据库」这些日常运维动作，收拢进一个可视化界面里，并能固化成**一键任务 / 部署流程**，下次点一下就跑完整套。

**不绑定任何具体项目，人人可用**；纯本地运行，不联网回传任何数据，服务器/数据库密码经操作系统密钥链加密存储。

---

## 🎯 它解决什么问题

部署或运维一台服务器，往往要在「文件管理器 / 终端 / 数据库工具」之间反复横跳，命令还得每次重敲。SFTPulse 把这些整合成一个带图形界面的桌面 App：

- 传文件不用记 `scp`，拖进去、选好目录、点上传即可，带队列和进度。
- 常用部署动作（上传产物 → 重启服务 → 健康检查）存成一个按钮，重复执行。
- 多个任务再串成一条「部署流程」，一键按序跑完，任一步失败立即中止。
- 需要时直接在内置终端里操作服务器，或把本地/远程 MySQL 互相同步。

## ✨ 功能

### 🔌 连接与安全
- **多连接管理**：保存多台服务器（主机 / 端口 / 用户名 / 密码或私钥），随时切换。
- **凭据加密**：密码 / 私钥口令用 Electron `safeStorage`（系统密钥链）加密后落盘，明文不写磁盘、不进 Git。

### 📁 文件传输与远程管理
- **上传**：选择文件或整个文件夹（递归保留目录结构），带**传输队列 + 实时进度**；支持把文件**直接拖进远程面板**上传。
- **远程浏览/操作**：进入目录、下载、删除（递归 + 确认）、重命名、新建目录。
- **可视化目录选择器**：任务的远程目录不用手打，弹出目录树浏览 + 新建文件夹，点选即得。

### 💻 交互式终端
- 内置 xterm.js 终端（对接 ssh2 pty），像 SecureCRT 一样直接操作服务器，窗口缩放自适应、断开自动回收。

### 🚀 一键任务
- 把「上传这些文件 + 按顺序执行这些命令」存成一个可重复运行的按钮：自动连接 → 递归上传 → 逐条执行，全程日志回显。
- **命令代码提示**：命令输入框内置常用命令库，按当前行前缀过滤，`↑/↓` 选择、`Tab` 采纳。
- **失败可见**：命令退出码非 0 会被标红并计入失败数，任务结尾汇总，不再"假成功"。
- **后台命令防卡死**：以 `&` 结尾的常驻命令（如 `nohup java -jar ... &`）自动用 `setsid` 脱离会话，界面即时返回，不会卡在"等退出码"。

### 🔗 部署流程（大任务）
- 把多个小任务串成一条流程（例如「部署后端」+「部署前端」），在流程上点「▶ 一键运行」即按序执行；任一任务失败立即中止后续步骤。

### 📌 窗口置顶
- 右上角"钉子"可把整个窗口**置顶**到所有软件之上，边看别的边盯部署进度。

### 🗄 数据库双向同步（MySQL / MariaDB）
- 独立配置数据库连接（主机 / 端口 / 账号 / 库），支持**本地 ↔ 服务器双向**同步。
- **按表**选择，**结构**（`SHOW CREATE TABLE` → 删除重建）与**数据**（分批读取 → 批量写入）分别可选。
- **先连接、再下拉选库**：填好服务器信息点「加载」，自动 `SHOW DATABASES` 列出可选库。
- **SSH 隧道**：数据库不可直连（未开 3306 / 在内网另一台机器）时，可经由某条已保存的 SSH 连接做跳板访问，无需对外开放数据库端口。

## 🖥 环境要求

- Windows 10 / 11
- 构建需 [Node.js](https://nodejs.org/) ≥ 18（含 npm）；**仅使用**则直接运行打包好的 exe，无需装 Node。

## 🚀 快速开始（开发）

```bash
npm install          # 安装依赖
npm run dev          # 开发模式，热更新并弹出应用窗口
npm run typecheck    # 类型检查
npm run build        # 仅构建到 out/
```

## 📦 打包成桌面 EXE

```bash
npm run dist         # 生成 Windows 安装包，输出到 dist/
```

产物（`dist/` 目录）：

| 文件 | 说明 |
| --- | --- |
| `SFTPulse-<版本>-setup.exe` | **安装版**：双击安装，自动创建桌面 / 开始菜单快捷方式，可改安装目录。 |
| `win-unpacked\SFTPulse.exe` | **免安装版**：直接双击运行；把整个 `win-unpacked` 文件夹拷到任意位置即可用。 |

> 想用自定义图标：放一张 256×256 的 `build/icon.ico`，然后在 `electron-builder.yml` 里取消 `icon:` 那行的注释，重新 `npm run dist`。

## 🧭 使用流程

1. **⚙ 连接管理 → 新建连接**，填服务器信息并保存；顶部下拉选中它，点「连接」。
2. **📁 文件传输**：左侧选文件/文件夹（或直接拖入右侧远程面板），进入目标目录点「上传」；行尾可下载/重命名/删除，工具栏可新建目录。
3. **💻 终端**：连接后自动打开交互式终端，直接敲命令。
4. **🚀 一键任务**：新建任务 → 绑定连接 → 选本地文件、用「浏览」选远程目录、写命令（带代码提示）→ 保存；之后点 ▶ 即一键执行。多个任务可「➕ 部署流程」串起来一键运行。
5. **🗄 数据库同步**：新建数据库连接（不可直连就选 SSH 隧道）→「加载」选库 → 保存；选源/目标、加载并勾选表、勾结构/数据 → 开始同步。
6. 需要边用别的软件边盯进度时，点右上角 📌 置顶窗口。

## 🗂 项目结构

```
SFTPulse/
├── src/
│   ├── main/                 # Electron 主进程
│   │   ├── index.ts          # 窗口创建与生命周期
│   │   ├── ipc.ts            # 所有 IPC 通道集中注册
│   │   ├── vault.ts          # SSH 连接持久化 + safeStorage 加密
│   │   ├── tasksStore.ts     # 一键任务 / 部署流程持久化（tasks.json / groups.json）
│   │   ├── taskRunner.ts     # 任务编排：自动连接 → 上传 → 逐条命令；流程按序执行
│   │   ├── dbStore.ts        # 数据库连接持久化 + safeStorage 加密（databases.json）
│   │   ├── dbSync.ts         # 数据库连接测试 / 枚举库表 / 结构+数据双向同步
│   │   ├── types.ts          # 跨进程共享类型
│   │   └── ssh/
│   │       ├── sshService.ts       # ssh2 封装：连接 / SFTP / 远程增删改 / 命令执行 / 本地端口隧道
│   │       └── terminalService.ts  # 交互式 shell(pty) 通道管理
│   ├── preload/              # contextBridge 白名单 API 桥接
│   └── renderer/             # Vue 3 + Element Plus 界面
│       └── src/
│           ├── App.vue
│           └── components/{ConnectionManager,FilesPanel,TerminalPanel,TasksPanel,DbPanel}.vue
├── electron.vite.config.ts

```

## 🔒 安全说明

- 渲染进程不直接接触 Node，所有敏感操作经 `preload` 白名单 IPC 转发。
- SSH / 数据库密码明文只在主进程建立连接的瞬间解密使用，绝不回传渲染进程，也不写入仓库。
- 本地配置（连接、任务、数据库）存于系统 `userData/sftpulse/` 目录，密码字段加密；仓库 `.gitignore` 已排除。
- 若系统不支持密钥链加密，退化为本地 base64 存储（带 `plain::` 标记），仍仅存于本机。
